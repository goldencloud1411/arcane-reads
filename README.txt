Arcane Reads v0.2

Qué incluye esta versión:
- Interfaz más pulida, más cercana a una app móvil real.
- Flujo para añadir libros de tres maneras:
  1) Buscar en línea (Google Books / Open Library)
  2) Importar CSV exportado de Goodreads
  3) Añadir manualmente
- Editor del libro con vista 3D para portada, lomo, canto y contraportada.
- Biblioteca visual con repisas.
- Sesiones de lectura y estadísticas básicas.
- Guardado local en el navegador mediante IndexedDB.

Cómo publicar en GitHub Pages:
1. Sube todos los archivos de esta carpeta al repositorio.
2. Activa GitHub Pages desde main / root.
3. Abre la URL del repo publicado y usa "Agregar a pantalla de inicio" o "Instalar aplicación".

Límites actuales / pendientes:
- Goodreads se importa por CSV, no por API directa.
- La sincronización automática entre dispositivos todavía no está conectada a una base de datos en la nube.
- El buscador en línea depende de Google Books y Open Library; algunos libros pueden necesitar edición manual después.
